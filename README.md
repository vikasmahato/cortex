# C.O.R.T.E.X

**C**ontinuous **O**bservation, **R**ecall & **T**hought **EX**traction — a local-first second brain for your Claude Code activity. See [PLAN.md](PLAN.md).

## Phase 1 — capture (done)

```bash
npm install
npm run backfill        # import all existing ~/.claude/projects transcripts into ~/.cortex/cortex.db
npm run daemon          # http://127.0.0.1:7777  (+ ws://127.0.0.1:7777/ws), live-tails transcripts
npm run install-hooks   # add live hooks to ~/.claude/settings.json (backup: settings.json.cortex-backup)
npm run uninstall-hooks
npm test
```

API: `GET /api/events | /api/sessions | /api/sessions/:id | /api/search?q= | /api/stats`, `POST /hook`.
WebSocket pushes `{type:'fire', signal}` (brain region + intensity) and `{type:'events'}`.

Data lives in `~/.cortex/` (override with `CORTEX_HOME`). Secrets are redacted before storage.

## Phase 3 — the brain (web UI)

```bash
npm run daemon      # terminal 1
npm run dev -w @cortex/web   # terminal 2 -> http://127.0.0.1:5173
```

Procedural 3D brain (React Three Fiber, custom shaders, selective bloom). Regions fire live from transcript
events (and instantly from hooks if installed). Click a region to filter; `Ctrl K` searches memory.

## Phase 2 — intelligence

```bash
npm run summarize -- --limit 20   # summarize past sessions (newest first); ~10s each
```

- LLM calls use `ANTHROPIC_API_KEY` if set, otherwise your logged-in `claude` CLI (`claude -p`, no session persistence, hooks ignored).
- The daemon auto-summarizes recent sessions once idle 15 min (max 2 per 5 min, last 3 days only). Disable: `CORTEX_AUTO_SUMMARIZE=0`.
- `POST /api/ask {question}` -> cited answer; `GET /api/browse?category=`, `GET /api/categories`, `POST /api/sessions/:id/summarize`.
- UI: `Ctrl K` = Ask Cortex / Search (Tab switches); **Browse** = categories + session summaries. Ask lights up the hippocampus, then the regions the memories came from.
- Retrieval is BM25 keyword search over summaries + events. Vector embeddings are not implemented yet.

## Brain model

The 3D brain is built from the FreeSurfer fsaverage cortical template (real MRI-derived folds), generated by
`tools/build_brain.py` into `apps/web/public/brain/`. See `apps/web/public/brain/NOTICE.md`. If the asset is missing the UI falls back to a procedural brain.

## Projects view (home screen)

The home screen is organised around *your* work: a project list (grouped from working directories by `projectFromCwd`, with each session
assigned to the project where most of its work happened), a per-project overview (what it is, threads of work with status, open items,
sessions, topics) and a Today panel. The brain tints to the selected project's kind of work. Project overviews are written by Haiku from
session summaries and cached (`project_profiles`); run `npm run summarize -- --limit 120` first so there is history to work from.

## Chat with Claude from a project

Open a project, then **Chat with Claude**. Cortex runs Claude Code headless in the project folder (found from your history), seeded with what Cortex knows
about the project. **Ask · read-only** restricts Claude to Read/Grep/Glob; **Can edit files** also allows Edit/Write (never shell commands, and not
available for generic locations like the home folder). Conversations are saved as normal sessions, so they show up in the project too.
The endpoint requires an `x-cortex-client` header and only accepts localhost origins.
